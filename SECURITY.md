# Security Policy

## Supported Versions

Security updates are applied to the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | Yes                |
| < 2.0   | No                 |

---

## Reporting a Vulnerability

We take the security of Markbel and its users seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send a report describing the vulnerability, affected components, proof-of-concept steps, and potential impact to the maintainer via GitHub Security Advisories or direct private contact.
3. We will acknowledge receipt within 48 hours and coordinate a fix and advisory prior to public disclosure.

Thank you for helping keep Markbel and its community secure.
